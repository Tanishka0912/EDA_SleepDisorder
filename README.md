# Sleep Disorder Analysis – Exploratory Data Analysis (EDA)

📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a Sleep Health and Lifestyle dataset to understand the relationship between lifestyle factors, health indicators, and sleep patterns.
The analysis explores factors such as sleep duration, sleep quality, stress levels, physical activity, BMI category, blood pressure, and sleep disorders. The objective is to identify patterns, trends, and potential relationships within the dataset using Python.

🎯 Objectives
- Understand the structure and characteristics of the dataset.
- Perform data cleaning and data quality checks.
- Identify and handle missing values and duplicate records, where applicable.
- Analyze sleep duration and sleep quality.
- Explore the relationship between lifestyle factors and sleep disorders.
- Visualize important patterns and insights using charts and graphs.
  
📂 Dataset Description
The dataset contains information about individuals' sleep health, daily habits, and selected health indicators.
Key features may include:
- Gender and Age: Demographic information.
- Occupation: Professional background.
- Sleep Duration: Average hours of sleep.
- Quality of Sleep: Self-reported sleep quality.
- Physical Activity Level: Daily physical activity.
- Stress Level: Reported stress level.
- BMI Category: Body mass index category.
- Blood Pressure: Systolic and diastolic blood pressure.
- Heart Rate: Heart rate measurements.
- Daily Steps: Number of steps taken per day.
- Sleep Disorder: Recorded sleep disorder category, if present.

🔍 Steps Performed
1. Data Loading: Imported the dataset using Pandas.
2. Data Understanding: Examined dataset dimensions, column names, data types, and summary statistics.
3. Data Quality Audit: Checked for missing values, duplicate records, and inconsistencies.
4. Data Cleaning: Applied appropriate cleaning steps where required.
5. Univariate Analysis: Examined individual variables using descriptive statistics and visualizations.
6. Bivariate Analysis: Explored relationships between sleep-related variables and lifestyle factors.
7. Data Visualization: Created charts to identify distributions, comparisons, and patterns.
8. Insights and Conclusion: Summarized the major findings from the analysis.
   
📊 Key Questions Explored
- How does sleep duration vary across different age groups?
- Is sleep quality associated with stress levels?
- How do sleep patterns differ across occupations?
- Which sleep disorder categories appear in the dataset?
- How do physical activity levels and BMI categories vary across sleep disorder groups?
- What patterns can be observed between lifestyle factors and sleep health?
